# 🚀 راهنمای حل مشکل عدم به‌روزرسانی سایت Trainova

## مشکل چیست؟
وقتی فایل‌های جدید را روی هاست آپلود می‌کنید، کاربران همچنان نسخه قدیمی را می‌بینند. این مشکل به دلیل **کش مرورگر** و **Service Worker** قدیمی است.

---

## ✅ راه‌حل‌های اعمال شده در نسخه 10.3

### ۱. Service Worker هوشمند (sw.js)
- **استراتژی Network-First**: وقتی اینترنت باشد، همیشه از سرور می‌خواند
- **پاک‌سازی خودکار**: تمام کش‌های قدیمی را حذف می‌کند
- **غیرفعال کردن آفلاین**: وقتی اینترنت هست، نسخه آفلاین اجرا نمی‌شود
- **ریدایرکت اجباری**: کاربران را به نسخه جدید هدایت می‌کند

### ۲. صفحه Force Update (force-update.html)
یک صفحه اختصاصی که:
- تمام Service Workerهای قدیمی را پاک می‌کند
- Cache Storage را خالی می‌کند
- LocalStorage را پاک‌سازی می‌کند
- کاربر را مجبور به بارگذاری نسخه جدید می‌کند

### ۳. کد پاک‌سازی در index.html
در اولین بارگذاری، تمام کش‌ها به صورت خودکار پاک می‌شوند.

---

## 📋 دستورالعمل استفاده

### روش ۱: استفاده خودکار (توصیه شده)
به محض اینکه کاربران سایت را باز کنند، سیستم به صورت خودکار:
1. Service Worker قدیمی را حذف می‌کند
2. کش‌ها را پاک می‌کند
3. نسخه جدید را از سرور بارگذاری می‌کند

### روش ۲: استفاده از صفحه Force Update
اگر مشکل ادامه داشت، کاربران باید به آدرس زیر بروند:
```
https://trainova.ir/force-update.html
```
این صفحه تمام کش‌ها را پاک کرده و نسخه جدید را بارگذاری می‌کند.

### روش ۳: پاک‌سازی دستی توسط کاربر
به کاربران بگویید:
1. کلیدهای `Ctrl + Shift + Delete` را بزنند
2. گزینه "Cached images and files" را انتخاب کنند
3. دکمه "Clear data" را بزنند
4. صفحه را Refresh کنند (`Ctrl + F5`)

## 🔧 مراحل آپلود روی هاست

### مرحله ۱: پاک‌سازی فایل‌های قدیمی
```bash
# تمام فایل‌های قدیمی را پاک کنید (به جز پوشه _next اگر Next.js استفاده می‌کنید)
rm -rf *.html *.js *.json *.svg *.png
```

### مرحله ۲: آپلود فایل‌های جدید
تمام فایل‌های جدید را آپلود کنید:
- `index.html`
- `sw.js` (خیلی مهم!)
- `version.json`
- `manifest.json`
- `force-update.html` (جدید)
- و سایر فایل‌ها

### مرحله ۳: بررسی صحت آپلود
مطمئن شوید فایل‌های جدید جایگزین شده‌اند:
```bash
# بررسی نسخه
cat version.json | grep version
```

### مرحله ۴: تست نهایی
1. سایت را در حالت ناشناس مرورگر باز کنید
2. Console را چک کنید (`F12`)
3. باید پیام `[Trainova SW v10.2-smart] loaded` را ببینید
4. باید پیام‌های پاک‌سازی کش را ببینید

## 🎯 نکات کلیدی برای جلوگیری از مشکل

### ۱. همیشه version.json را آپدیت کنید
با هر بار تغییر، عدد نسخه را افزایش دهید:
```json
{
  "version": "10.3"  // ← این را تغییر دهید
}
```

### ۲. نام فایل‌ها را تغییر ندهید
فایل‌های اصلی باید نام ثابت داشته باشند:
- ✅ `sw.js`
- ✅ `index.html`
- ✅ `manifest.json`

### ۳. از Query Parameter استفاده کنید
برای فایل‌های استاتیک از timestamp استفاده کنید:
```html
<script src="script.js?v=10.3"></script>
<link rel="stylesheet" href="style.css?v=10.3">
```

### ۴. هدرهای HTTP را تنظیم کنید
در سرور خود این هدرها را اضافه کنید:
```
Cache-Control: no-cache, no-store, must-revalidate
Pragma: no-cache
Expires: 0
```

برای فایل‌های HTML و JSON.

## 🐛 عیب‌یابی

### مشکل: هنوز نسخه قدیمی نمایش داده می‌شود
**راه‌حل:**
1. به آدرس `force-update.html` بروید
2. کش مرورگر را دستی پاک کنید
3. از حالت ناشناس استفاده کنید

### مشکل: Service Worker unregister نمی‌شود
**راه‌حل:**
1. DevTools را باز کنید (`F12`)
2. به تب Application > Service Workers بروید
3. دکمه "Unregister" را بزنید
4. صفحه را Reload کنید

### مشکل: کش پاک نمی‌شود
**راه‌حل:**
1. DevTools را باز کنید (`F12`)
2. به تب Application > Storage بروید
3. دکمه "Clear site data" را بزنید
